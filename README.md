# EO-Algorithms-MATLAB-Simulink

This repository contains MATLAB/Simulink-based algorithm studies developed for electro-optical applications.

Projects:

- Adaptive EO/IR Sensor Selection Algorithm
- Adaptive EO Field-of-View Management Algorithm
- EO Gimbal Angular Tracking Control Algorithm
- Kalman Filter Based Line-of-Sight Estimation Algorithm

The studies focus on fundamental EO systems engineering topics including sensor selection, optical mode management, closed-loop control, and state estimation.
